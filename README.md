# کتاب‌بُر
این برنامه با کمک هوشمص کلاد نوشته شده و کار آن تبدیل pdfهای دوصفحه‌ای به تک‌صفحه‌ای است.

# فایل اجرایی برای ویندوز
در بخش [Releases](https://github.com/pushideh/KetabBor/releases) می‌توانید فایل قابل اجرا در ویندوز ۶۴ بیتی را دریافت کنید. با اجرای برنامه چند گزینه وجود دارد:
- در بخش `انتخاب فایل` می‌توانید فایل pdfای را که می‌خواهید صفحات‌ش را از هم جدا کنید انتخاب کنید.
- در بخش `انتخاب پوشه` می‌توانید پوشه‌ای را که حاوی چند pdf است انتخاب کنید و همه را با هم جداسازی کنید.
- `جهت کتاب` به این معناست که ترتیب ورق زدن کتاب از راست به چپ است مانند پارسی و عربی، یا چپ به راست است مانند انگلیسی و آلمانی و...
- بخش dpi کیفیت تصویر خروجی را مشخص می‌کند. میزان ۳۰۰ یک کیفیت طبیعی و معمولی ارائه می‌دهد و برای سندهای سیاه و سپید متداول است. با کم کردن این عدد می‌توانید حجم فایل خروجی را کاهش دهید.
- `نسبت برش` محل برش زدن صفحه‌ها را مشخص می‌کند. ۰.۵ یعنی دقیقا وسط. هر چه این عدد کم‌تر شود (مثلا ۰.۴۵) خط برش به سمت چپ می‌رود و هر چه این عدد بیش‌تر شود (مثلا ۰.۵۵) خط برش به سمت راست می‌رود.
- اگر هم کتاب جلد دارد می‌توانید گزینه‌ی `صفحه‌ی اول بدون تغییر` را فعال کنید.

**توجه**: تا زمانی که پیام پایان یافتن موفقیت‌آمیز پردازش را ندید صبر کنید. چون پس از پایان برش صفحه‌ها مدتی زمان لازم است تا فایل pdf آماده‌سازی شود.

# فایل پایتون

## راهنمای نصب و اجرا

### ۱) پیش‌نیازها (روی ویندوز)

1. نصب Python 3.10 یا بالاتر از [python.org](https://www.python.org/downloads/) — هنگام نصب حتماً تیک **Add python.exe to PATH** زده شود.
2.  در PowerShell یا CMD این دستور را وارد کنید تا پیش‌نیازهای برنامه نصب شود:

```
pip install -r https://raw.githubusercontent.com/pushideh/KetabBor/refs/heads/main/requirements.txt
```

این دو کتابخانه نصب می‌شود:
- `pymupdf` (fitz) — موتور اصلی خواندن/نوشتن PDF
- `pillow` — برش و پردازش تصویر

### ۲) اجرا

```
python https://raw.githubusercontent.com/pushideh/KetabBor/refs/heads/main/ketabBor.py "book.pdf" -o "book_split.pdf" --rtl
```

- برای کتاب فارسی/عربی از `--rtl` استفاده کنید (نیمه‌ی راست هر صفحه اول می‌آید).
- برای کتاب انگلیسی/چپ‌به‌راست از `--ltr` استفاده کنید.
- اگر صفحه‌ی جلد نباید نصف شود: `--keep-first`
- اگر خط تا کتاب دقیقاً وسط نیست: `--split-ratio 0.48` (مثلاً کمی به چپ)
- برای پردازش کل یک پوشه به‌جای یک فایل:
```
python https://raw.githubusercontent.com/pushideh/KetabBor/refs/heads/main/ketabBor.py "InputFolder" -o "OutputFolder" --rtl
```

### ۳) رابط گرافیکی (Drag & Drop)

به‌جای خط فرمان می‌توانید از رابط گرافیکی `gui.py` استفاده کنید. برای این منظور می‌تواندی در cmd بنویسید:

```
python https://raw.githubusercontent.com/pushideh/KetabBor/refs/heads/main/gui.py
```

- اگر `pip install tkinterdnd2` را هم زده باشید، می‌توانید فایل/پوشه‌ی PDF را مستقیم روی کادر بکشید و رها کنید.
- اگر tkinterdnd2 نصب نباشد، برنامه به‌طور خودکار فقط با دکمه‌های «انتخاب فایل» / «انتخاب پوشه» کار می‌کند — هیچ مشکلی پیش نمی‌آید.
- مسیر خروجی به‌صورت خودکار پیشنهاد داده می‌شود (قابل تغییر).
- جهت کتاب، DPI، نسبت برش و کپی بدون تغییر جلد همگی از داخل پنجره قابل تنظیم‌اند.

## نکته‌ی کیفیت

اسکریپت اول تلاش می‌کند تصویر جاسازی‌شده در PDF را مستقیم استخراج و برش بزند (بدون افت کیفیت اضافه). فقط اگر صفحه یک تصویر ساده‌ی تمام‌صفحه نبود (مثلاً وکتور یا چند تکه)، آن را با DPI بالا (پیش‌فرض ۳۰۰، قابل افزایش با `--dpi 400` یا `--dpi 600`) رندر می‌کند.
